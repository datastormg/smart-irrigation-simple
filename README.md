# smart-irrigation-simple

# الري الذكي — Smart Irrigation Simple 
##ا مهم جدا ==> تحديث الكود هو ( Smart_Irrigation_Far_Control_GitHub3 )

مشروع ESP32 NodeMCU لعرض رطوبة عبوتين والتحكم بمضختين من الجوال محليًا وعبر الإنترنت. يستخدم خادم Mosquitto العام الجاهز دون إنشاء حساب MQTT.

## التوصيلات

| المكوّن | GPIO |
|---|---|
| الحساس الأول AOUT | 32 |
| الحساس الثاني AOUT | 33 |
| الريلي الأول IN | 25 |
| الريلي الثاني IN | 26 |
| مفتاح اللمس الأول OUT | 18 |
| مفتاح اللمس الثاني OUT | 19 |

الحساسان ومفتاحا TTP223 بتغذية 3.3V. وحدتا الريلي بمصدر 5V مناسب وأرضي مشترك مع ESP32، وبمدخل تحكم متوافق مع 3.3V. تغذية المضخات منفصلة وبالجهد المحدد عليها: موجب المصدر إلى COM، وNO إلى موجب المضخة، وسالب المضخة إلى سالب مصدرها.

## برنامج المتحكم

- اللوحة: ESP32 Dev Module للوحة ESP32 NodeMCU المبنية على ESP32-WROOM-32.
- المكتبات الإضافية: PubSubClient وArduinoJson الإصدار 7.
- ارفع Smart_Irrigation_Simple.ino إلى ESP32 من Arduino IDE.
- يبدأ الجهاز والمضختان متوقفتان، والتلقائي غير مفعّل.
- مستوى تشغيل الريلي مضبوط HIGH لكل قناة. عدّل كل عنصر في RELAY_ON بحسب اختبار وحدتك.

## الاتصال بالإنترنت من أيقونة Wi-Fi

1. اتصل من الجوال بشبكة SMART_IRRIGATION.
2. كلمة المرور Irrigate2026.
3. افتح http://192.168.4.1.
4. اضغط أيقونة 📶 ثم بحث.
5. اختر شبكة راوتر 2.4GHz، وأدخل كلمة مرورها، واضغط حفظ واتصال.
6. انتظر ظهور اتصال الراوتر والتحكم البعيد في أعلى الصفحة.

تحفظ بيانات الراوتر داخل ESP32. عند حفظ شبكة جديدة تتوقف المضختان ويُلغى التلقائي. تغيير شبكة الجهاز يتم وأنت بجواره من هذه الصفحة؛ أيقونة Wi-Fi على موقع GitHub تشرح طريقة الوصول إليها. كلمة مرور الراوتر لا تُرسل إلى MQTT أو GitHub.

## نشر صفحة الجوال

1. أنشئ مستودع GitHub عامًا.
2. ضع index.html وREADME.md و.nojekyll و.gitignore في جذر المستودع.
3. افتح Settings ثم Pages.
4. اختر Deploy from a branch ثم main ثم /(root)، واحفظ.
5. افتح رابط الموقع بعد اكتمال النشر؛ الاتصال بالمتحكم يتم تلقائيًا.
6. اختبر باستخدام بيانات الجوال، مع إبقاء ESP32 متصلًا براوتر لديه إنترنت.

## التشغيل والمعايرة

- لكل مضخة تشغيل وإيقاف يدوي وتلقائي مستقل، ولمسة TTP223 تبدّل التشغيل وتلغي التلقائي للقناة.
- حد بدء الري الافتراضي 50%، ويمكن ضبطه من 5% إلى 90%؛ التوقف عند الحد + 10%.
- معايرة كل حساس تتم من الصفحة المحلية فقط، بعد إيقاف المضختين والتلقائي.
- ضع الحساس في التربة الجافة واحفظ «معايرة جاف»، ثم في التربة المرجعية المبللة واحفظ «معايرة مبلل» وانتظر استقرار القراءة في الحالتين. لا تغمر إلكترونيات الحساس.
- النسبة مقياس نسبي بين نقطتي المعايرة، وليست نسبة مخبرية لكمية الماء المضاف.
- تتوقف المضختان لحظيًا أثناء التشغيل لأخذ قراءات بتشويش أقل. القراءة تثبت أثناء الضخ وتوضح الواجهة ذلك.
- توقف وقائي بعد 60 ثانية لكل تشغيل، مع إلغاء التلقائي للقناة. يمكن إعادة تشغيلها يدويًا أو إعادة تفعيل التلقائي.
- فصل صفحة الجوال أو الإنترنت لا يوقف المضخات فورًا؛ يبقى منطق الجهاز والإيقاف الوقائي فعالين.

## إعدادات الاتصال الجاهزة

الموضوع نفسه مكتوب في البرنامج والصفحة؛ عند تغييره يجب تحديث الملفين. اسم الموضوع ليس كلمة مرور. تعتمد الصفحة على مكتبة MQTT.js 5.10.4 من jsDelivr.

## حدود النسخة التجريبية

الخادم عام ويمكن للآخرين قراءة الرسائل والنشر على المواضيع. هو مخصص للاختبار، ولا يضمن التوافر. اختبر المضخات تحت المراقبة. لم يُختبر البرنامج على دائرتك الفعلية؛ نجاح فحوص المنطق والواجهة لا يثبت سلامة التوصيل أو عمل الريلي مع 3.3V.
